## Featured project: ReelShield

**[View the repository](https://github.com/siddharth-kasturi/Reelsheild)**

ReelShield is an experimental Android productivity app that uses Android's Accessibility Service to recognize selected short-form video interfaces and display a blocking overlay. Its goal is to make short-form feeds harder to access without blocking an entire social app.

- **Platform:** Android
- **Language:** Java
- **Core technology:** Android Accessibility Service
- **What I'm working on:** UI detection, overlay behavior, debugging, and real-device testing
- **Status:** Experimental; compatibility varies across apps and versions

The project has not established measured reductions in screen time or improvements in focus. I'm interested in learning how software interventions like this could be evaluated more rigorously.
